# Design

InputLeap Windows control surface in Material Design 3 (dark, teal seed).

## World

MD3 tonal surfaces. Primary teal for the live link. Filled / tonal / outlined buttons. 16–20dp corners. Desk strip shows which machine sits on which edge.

## Surface

- Top app bar + status chip
- Server | Client surface-container cards
- Desk strip: left chip ↔ right chip
- Shared folder card: path, send, open
- Footer: outlined Aplicar + filled Início/Parar
